# NinjaGrude Media Landing Page

A one-page, static landing site for NinjaGrude Media designed for AWIN verification and future scale. It is fast, editorial, and compliant with a clear content and monetization statement.

## Preview locally
Open `index.html` directly in your browser.

## Deploy on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/** (root).
5. Save. Your site will be available shortly.

## AWIN readiness checklist
- [ ] URL is public and accessible.
- [ ] Site clearly states what we publish and how we monetize.
- [ ] Contact information is visible (email address).

## Common updates
- Update the brand name in `index.html` (search for “NinjaGrude Media”).
- Update the email address in `index.html` (search for `ninjagrude@gmail.com`).
- Update colors and layout in `assets/styles.css`.
